# MOP有効F統計量のオラクル（独立実装）仕様

Montiel Olea and Pflueger (2013)の有効F統計量と臨界値を、engineのRust実装とは別に、Python（numpy/scipy）で
独立に実装する。engineの実装結果を照合する参照値を作るのが目的。別セッションで実装する。

## 0. 守ること（来歴の管理）

この実装は、論文の式だけから書き起こす。次を**見ない・取得しない・参考にしない**:

- Stataの`weakivtest.ado`と、それを他言語へ移したもの（ライセンス表記が無く、権利が留保されている）
- そのコードの構造・変数名・手順（グリッド点数、許容誤差、最適化の手法など）

見てよいもの:

- 論文: Montiel Olea, J. L. and Pflueger, C. (2013), "A Robust Test for Weak Instruments", *Journal of Business &
  Economic Statistics* 31(3), 358-369。入手先: https://cpflueger.github.io/carolinpflueger_repository/MOP_FINAL_May14.pdf
  （PDFはテキスト抽出できる。`uv pip install --target <一時ディレクトリ> pypdf`で`pypdf`を使える。リポジトリの依存には入れない）
- RのivDiag 1.0.8（CRAN、MITライセンス）。**実行して数値を取る**のと、ソースを読むのは可
- リポジトリの既存の記述: `docs/spec/iv-spec.md`3.4.1・3.4.2節（Cragg-DonaldとKleibergen-Paapの定義と`cov_type`の規約）

実装の中身（ループの形、最適化の手法、分解の順序）は自分で設計する。式を満たし、精度の条件（6章）を満たせばよい。

## 2. 設定と記号

内生変数1個。観測数`S`、除外操作変数`K`個、外生変数`k_exog`個（定数列を含む）、吸収したパラメータ数`n_absorbed`（既定0）、
`l = K + k_exog`。入力は`(y, Y, X_exog, Z)`で、`y`は被説明変数、`Y`は内生変数（`S`ベクトル）。

論文の誘導形（Eq. (1), (2)）: `y = ZΠβ + v1`、`Y = ZΠ + v2`。

**前処理（論文2.2.1節Step 1）**: `X_exog`（定数列を含む。平均は引かず、他の列と同じく回帰で落とす）で`y`・`Y`・`Z`を直交化し、
さらに`Z`を`Z'Z/S = I_K`となるように直交正規化する（以下この`Z`を`Z̃`と書く）。有効Fはこの変換に依存しない。

誘導形の係数と残差: `π̂ = Z̃'Y/S`、`π̂_y = Z̃'y/S`、`e2 = Y − Z̃π̂`、`e1 = y − Z̃π̂_y`。
観測`i`のスコア: `s_i = (z̃_i e1_i ; z̃_i e2_i)`（2K次元。前半が`y`、後半が`Y`）。

## 3. 共分散の推定（`cov`の種類）

`Ŵ`は`√S·(π̂_y ; π̂)`の漸近共分散の推定値（論文のAssumption HL）。これを2K×2Kで作り、ブロックを
`Ŵ = [[Ŵ1, Ŵ12],[Ŵ12', Ŵ2]]`と書く（`Ŵ1`が`y`、`Ŵ2`が`Y`のK×K）。

meat `M`（2K×2K）と小標本の係数`c`を次で定義し、`Ŵ = c·M/S`とする（`classical`だけは`Ŵ`を直接書く）。

| `cov` | `M` | `c` |
|---|---|---|
| `classical` | （`Ŵ = c·(Ω̂⊗I_K)`。`Ω̂ = [e1 e2]'[e1 e2]/S`は2×2） | `S/(S − l − n_absorbed)` |
| `hc0` | `Σ_i s_i s_i'` | 1 |
| `hc1` | `Σ_i s_i s_i'` | `S/(S − l − n_absorbed)` |
| `hc2` | `Σ_i s_i s_i'/(1 − h_i)` | 1 |
| `hc3` | `Σ_i s_i s_i'/(1 − h_i)²` | 1 |
| `cluster` | `Σ_g (Σ_{i∈g} s_i)(Σ_{i∈g} s_i)'` | `G/(G−1)·(S−1)/(S − l − n_absorbed)` |
| `hac` | `Γ_0 + Σ_{j=1}^{L}(1 − j/(L+1))(Γ_j + Γ_j')`、`Γ_j = Σ_{t=j+1}^{S} s_t s_{t−j}'` | `S/(S − l − n_absorbed)` |

- `h_i`は`[X_exog, Z]`（直交化前）の射影行列の対角要素。`hc2`・`hc3`は`n_absorbed = 0`のときだけ定義する
  （`n_absorbed > 0`は未定義として扱う）。
- `hac`の`L`は`lags`（Bartlett核。時間順は観測の並び）。`cluster`は`G`個のグループ。
- `classical`では`Ŵ2 = c·ω̂_22·I_K`（`ω̂_22 = e2'e2/S`）で、`F_eff`はCragg-Donaldの`F`に一致する。係数`c`の置き方は、
  リポジトリの`docs/spec/iv-spec.md`3.4.2節（Kleibergen-Paapの`cov_type`の規約）と同じ考え方。

**注意**: 論文の`Ŵ`は`√S`倍した量（"divided by the sample size S"の記述はパッケージが返す共分散の話）。ここでは
`Ŵ`を漸近共分散（`S`倍した量）として定義し、`V̂2 ≡ Ŵ2/S`を`π̂`の共分散推定として使う。

## 4. 有効F統計量（論文Eq. (3)、Lemma 1.5）

`F_eff = π̂'π̂ / tr(V̂2)`　（`= S·π̂'π̂/tr(Ŵ2)`。論文のEq. (3)は`Z̃'Z̃/S = I`の下で同じ式）

## 5. 臨界値（論文2.2.1節Step 4、2.2.2節、Eq. (4)(5)(26)-(33)、Definition 2）

水準`α`（既定0.05）、閾値`τ`（0.05, 0.10, 0.20, 0.30）、`x`を非心度の入力として:

- 有効自由度（Eq. (4)、(33)）:
  `K_eff(x) = tr(Ŵ2)²(1 + 2x) / [tr(Ŵ2'Ŵ2) + 2x·tr(Ŵ2)·λ_max(Ŵ2)]`（`K_eff`は小数でよい）
- Patnaik臨界値（Eq. (32)）: `c(α, Ŵ2, x) = F^{-1}(1−α) / K_eff`。`F^{-1}`は自由度`K_eff`・非心度`x·K_eff`の
  非心カイ二乗分布の分位点（`scipy.stats.ncx2`は小数の自由度を受け付ける）。
- **単純版TSLS**（2.2.2節）: `x = 1/τ`（`τ=0.30`は`10/3`を厳密に使う）。
- **一般化TSLS**（Eq. (5)、(27)）: `x = B_TSLS(Ŵ)/τ`。

### 5.1 `B_TSLS(Ŵ)`（Theorem 1、Eq. (19)(21)、Remark 5）

`β ∈ R`について `S1 = Ŵ1 − 2βŴ12 + β²Ŵ2`、`S12 = Ŵ12 − βŴ2`、`S2 = Ŵ2`、
`BM(β) = √(tr(S1)/tr(S2))` とする。単位球面上の`C0`について

`n_TSLS(β, C0) = tr(S12)/tr(S2)·[1 − 2·C0'S12C0/tr(S12)]`、
`B_TSLS(Ŵ) = sup_{β∈R, C0∈S^{K−1}} |n_TSLS(β, C0)| / BM(β)`（Eq. (21)）。

`C0`についての上限は、`(S12+S12')/2`の固有値の最小・最大で解析的に取れる（Remark 5）。`β`についての上限は、
`β → ±∞`の極限（式から導く）を含めて、大域的に最大化する。`Ŵ`のスケールには依らない。Theorem 1.3より`B_TSLS ≤ 1`。
LIMLは対象外（このプロジェクトにLIMLの推定量が無い）。

## 6. 精度の条件

- 有効Fと臨界値は、相対誤差`1e-10`で正しいこと（浮動小数点の範囲で）。
- `B_TSLS`は相対誤差`1e-8`以内。**少なくとも2つの異なる最大化の方法**（例: 粗い格子+局所探索と、別の変数変換での探索）で
  同じ値になることを確かめ、その結果を値の表に書く。
- 結果の表は有効数字15桁以上。

## 7. 作るテストケース

データは自分で生成してよい式を以下に定める（Rust側のテストも同じデータを使う）。`i = 0, …, S−1`。

**D1（S=12、k_exog=2: 定数と`x`、K=3）**: 次の配列（添字は観測順）。
- `x  = [0.3,-1.2,0.8,2.0,-0.5,1.1,0.7,-0.4,1.6,0.2,-1.0,0.9]`
- `z1 = [1.0,0.2,-0.7,1.5,0.9,-1.1,0.3,0.8,-0.6,1.2,-0.3,0.5]`
- `z2 = [0.4,-0.9,1.3,0.1,-0.2,0.7,-1.4,0.6,0.0,-0.8,1.1,0.35]`
- `z3 = [-0.5,0.7,0.2,-1.1,0.8,0.4,1.0,-0.3,0.9,-0.6,0.15,-0.2]`
- `u1 = [0.2,-0.5,0.1,0.4,-0.3,0.6,-0.2,0.05,-0.45,0.3,0.15,-0.1]`
- `u2 = [-0.3,0.4,0.5,-0.2,0.1,-0.6,0.35,0.2,-0.1,-0.4,0.25,0.3]`
- `Y = 0.9 z1 − 0.4 z2 + 0.3 x + u1`、`y = Y − 0.5·(0.2 z1 + 0.7 z3 − 0.2 x + u2) + 0.1 x + u1`
- `cluster`のグループは`i // 3`（4グループ）、`hac`は`lags=2`、時間順は`i`。

**D2（S=240、k_exog=2: 定数と`x`、K=4）**:
- `x_i = sin(0.7 i + 0.3) + 0.5 cos(0.11 i)`
- `Z_il = sin(1.3 i (l+1) + l) + 0.3 cos(0.37 i (l+2))`（`l = 0,1,2,3`）
- `h_i = 1 + 0.8 |sin(0.05 i)|`、`e1_i = sin(2.1 i + 1.0)·h_i`
- `Y = 0.5 Z_0 + 0.3 Z_1 − 0.2 Z_2 + 0.1 Z_3 + 0.4 x + e1`
- `y = Y + 0.5 x + cos(0.9 i)·h_i`
- `cluster`のグループは`i // 12`（20グループ）、`hac`は`lags=4`、時間順は`i`。
- `D2` の`K=3`版（`Z_3`を使わず、`Y`の式から`0.1 Z_3`を除く）も作る。

**ケース**:
- D1・D2（K=4）・D2（K=3）× `cov ∈ {classical, hc0, hc1, hc2, hc3, cluster, hac}` × `n_absorbed = 0`。
- D2（K=4）× `cov ∈ {classical, hc1, cluster, hac}` × `n_absorbed = 3`。
- D2（K=4）の`hc1`で`α = 0.10`も1ケース。

各ケースで書き出す値: `F_eff`、`tr(V̂2)`、`Ŵ2`の固有値（降順）、`B_TSLS`、
`τ ∈ {0.05, 0.10, 0.20, 0.30}`それぞれについて、単純版の`(K_eff, 臨界値)`と、一般化版の`(x, K_eff, 臨界値)`。

## 8. オラクル自身の確認（必須）

実装したオラクルが次を満たすことをテストにする（論文の公表値や、仕様書の式に依存しない確認）。

1. **論文のTable 1**（30×4）を、小数第2位まで再現する（`x = 3.33`の列は`x = 10/3`）。許容は丸めの`0.005`。
2. **論文2.2.3節の公表値**: 同次分散（`Ŵ = Ω⊗I_K`）で一般化TSLS、`τ = 0.10`、`α = 0.05`の臨界値が、
   `K = 3`で`8.53`、`K = 30`で`12.27`（小数第2位）。同次分散では`B_TSLS = |1 − 2/K|`になる（導出して確かめる）。
3. **`K = 1`**: `B_TSLS = 1`、`K_eff = 1`、臨界値は`ncx2.ppf(1−α, 1, x)`。
4. **classical**: `F_eff`が、同じデータでlinearmodelsの`cragg_donald_f`（`IV2SLS`の診断）と相対`1e-10`で一致する。
5. **ivDiag 1.0.8の`eff_F`**との比較（`cov`は`hc1`相当（`robust`）と`cluster`。ivDiagの自由度補正の規約は
   lfeのものなので、**一致するかを実測して表に書く**。一致しないときは、どの係数だけ違うかを調べて書く）。
   ivDiagはdevcontainerに未導入。一時ディレクトリへ入れる（`Rscript -e 'install.packages("ivDiag", lib="<dir>")'`）。
   リポジトリの`Dockerfile`は変更しない。
6. **不変性**: 列のスケール倍、`Z`の正則な線形結合、行の並べ替え（`hac`以外）で、`F_eff`と臨界値が変わらない。
7. **FWL**: D2で、`x_exog`に個体ダミー（`i // 12`）を入れて`n_absorbed = 0`で計算した値と、`y`・`Y`・`Z`を
   個体ごとに平均除去して`n_absorbed = 20`（ダミーの数。定数列は入れない）で計算した値が、`classical`・`hc1`・`cluster`で一致する。
