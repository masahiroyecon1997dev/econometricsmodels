## 1. 概要

内生変数を含む線形モデルに対する操作変数 (IV) 推定量群。

| 推定量 | 概要 |
|--------|------|
| **IV** | 操作変数が内生変数と同数（just identified）の場合 |
| **2SLS** | 過剰識別を含む、最も一般的な IV 推定量 |
| **LIML** | 有限標本で優れた性質を持つ（Small-sample correction） |
| **GMM** | 最効率的（HAC ウェイトで系列相関にも対応） |
| **CUE** | Continuous Updating GMM（反復不要） |

---

## 2. 数理モデル

### 2.1 線形 IV モデル

$$
y = X\beta + \varepsilon
$$

$$
X = [X_1, X_2], \quad Z = [X_1, Z_2]
$$

| 記号 | 次元 | 説明 |
|------|------|------|
| $y$ | $n \times 1$ | 被説明変数 |
| $X_1$ | $n \times k_1$ | 外生説明変数 |
| $X_2$ | $n \times k_2$ | 内生説明変数 |
| $Z_2$ | $n \times l_2$ | 操作変数（$l_2 \geq k_2$） |
| $Z$ | $n \times l$ | 全操作変数（$l = k_1 + l_2$） |

識別条件: $l_2 \geq k_2$（操作変数の数 ≥ 内生変数の数）

### 2.2 2SLS 推定量

**第1ステップ**（内生変数を Z に回帰）:

$$
\hat{X}_2 = Z(Z^\top Z)^{-1}Z^\top X_2 = P_Z X_2
$$

**第2ステップ**（フィッテッド値で OLS）:

$$
\hat{\beta}_{2SLS} = (\hat{X}^\top X)^{-1} \hat{X}^\top y
= (X^\top P_Z X)^{-1} X^\top P_Z y
$$

### 2.3 GMM 推定量

**モーメント条件**: $E[Z_i \varepsilon_i] = 0$

サンプルモーメント: $g(\beta) = \frac{1}{n} Z^\top (y - X\beta)$

GMM 目的関数:

$$
\hat{\beta}_{GMM} = \arg\min_\beta \, g(\beta)^\top W^{-1} g(\beta)
$$

$W$: ウェイト行列

| ウェイト選択 | 内容 |
|-------------|------|
| $W = Z^\top Z / n$ | 2SLS と等価（効率的でない） |
| $W = \frac{1}{n}\sum_i Z_i^\top \hat{\varepsilon}_i^2 Z_i$ | 最効率 GMM（ヘテロ分散ロバスト） |
| HAC ウェイト | Newey-West 推定量（系列相関ロバスト） |

### 2.4 LIML 推定量

$$
\hat{\beta}_{LIML} = \hat{\beta}_{2SLS} \text{ (最小固有値調整)}
$$

LIML は 2SLS の特殊なクラスに属し、有限標本バイアスが小さい。

## 3. 標準誤差・診断検定

### 3.1 標準誤差

**古典的 2SLS SE**:

$$
\widehat{\text{Var}}(\hat{\beta}_{2SLS}) = \hat{\sigma}^2 (X^\top P_Z X)^{-1},
\quad \hat{\sigma}^2 = \frac{(y - X\hat{\beta})^\top(y - X\hat{\beta})}{n - k}
$$

**ロバスト SE** (HC 系・クラスター): OLS と同様のサンドイッチ推定量を 2SLS の行列で適用。

### 3.2 診断検定

#### ① 弱操作変数検定（第1ステップ F 統計量）

内生変数1つの場合:

$$
F = \frac{R^2_{1st} / k_2}{(1 - R^2_{1st}) / (n - k)}
$$

**判断基準**: $F < 10$ で弱操作変数を疑う（Stock-Yogo 臨界値を表で提供）

複数内生変数: Kleibergen-Paap rk ウォルド統計量

#### ② 過剰識別検定（Sargan-Hansen J 検定）

操作変数が外生であるか（over-identifying restrictions の検定）:

$$
J = n \cdot g(\hat{\beta})^\top \hat{W}^{-1} g(\hat{\beta}) \sim \chi^2(l_2 - k_2)
$$

有効な操作変数→ $J$ は小さい（帰無仮説: 操作変数が外生）

#### ③ 内生性検定（Durbin-Wu-Hausman 検定）

$$
DWH = (\hat{\beta}_{OLS} - \hat{\beta}_{2SLS})^\top
[Var(\hat{\beta}_{2SLS}) - Var(\hat{\beta}_{OLS})]^{-}
(\hat{\beta}_{OLS} - \hat{\beta}_{2SLS}) \sim \chi^2(k_2)
$$

有意 → $X_2$ が内生（OLS は一致性を持たない）

#### ④ Anderson-Rubin 検定

弱操作変数に対してロバストな内生係数の検定。

## 4. Rust 構造体・インターフェース

```rust
pub enum IvEstimator {
    TwoSls,
    Liml,
    Gmm { weight: GmmWeight },
    Cue,
}

pub enum GmmWeight {
    TwoSls,                    // W = Z'Z/n
    Efficient,                 // ヘテロ分散ロバスト
    Hac { lags: Option<usize> }, // Newey-West
}

pub struct IvConfig {
    pub estimator: IvEstimator,
    pub add_constant: bool,
    pub cov_type: CovType,
    pub cluster_col: Option<String>,
    /// 第1ステップ診断の出力
    pub first_stage_diagnostics: bool,
}

pub struct IvResults {
    pub params: Array1<f64>,
    pub std_errors: Array1<f64>,
    pub t_stats: Array1<f64>,
    pub p_values: Array1<f64>,
    pub conf_int: Array2<f64>,
    pub residuals: Array1<f64>,
    pub fitted_values: Array1<f64>,
    pub r_squared: f64,
    pub nobs: usize,
    pub param_names: Vec<String>,
    /// 診断検定
    pub diagnostics: IvDiagnostics,
}

pub struct IvDiagnostics {
    /// 第1ステップ: 内生変数ごとの F 統計量
    pub first_stage_f: Vec<(String, f64, f64)>,  // (var_name, F, p_value)
    /// Kleibergen-Paap rk 統計量 (複数内生変数)
    pub kp_stat: Option<f64>,
    /// Sargan-Hansen J 検定
    pub j_stat: Option<f64>,
    pub j_p_value: Option<f64>,
    /// Durbin-Wu-Hausman 検定
    pub dwh_stat: f64,
    pub dwh_p_value: f64,
    /// 第1ステップ OLS 結果
    pub first_stage_results: Vec<OlsResults>,
}
```

## 5. Python API

```python
import econometrics as em
import polars as pl

df = pl.read_csv("mroz.csv")

# 2SLS
model = em.IV2SLS(
    y="lwage",
    x_exog=["educ", "exper", "exper_sq"],   # 外生変数
    x_endog=["hours"],                        # 内生変数
    instruments=["kids_lt6", "nwifeinc"],     # 操作変数（Z2）
    data=df,
    add_constant=True,
    cov_type="HC1",
)
result = model.fit()
print(result.summary())

# 診断検定
diag = result.diagnostics
print(f"第1ステップ F: {diag.first_stage_f}")
print(f"Sargan J 検定: stat={diag.j_stat:.3f}, p={diag.j_p_value:.3f}")
print(f"DWH 内生性検定: stat={diag.dwh_stat:.3f}, p={diag.dwh_p_value:.3f}")

# GMM（最効率）
model_gmm = em.GMM(
    y="lwage",
    x_exog=["educ", "exper"],
    x_endog=["hours"],
    instruments=["kids_lt6", "nwifeinc", "fatheduc"],
    data=df,
    weight="efficient",
)
result_gmm = model_gmm.fit()

# LIML
model_liml = em.LIML(y="lwage", x_exog=[...], x_endog=[...], instruments=[...], data=df)
result_liml = model_liml.fit()
```
